# CHANGELOG · 酒店问答助手

本目录记录 `src/hotel-assistant/` 的版本演进。归档版本从阶段 1 原型（纯 CLI）延续而来。

## v1.0.0 — 2026-11-06（归档）

三角色协同版定版归档。

- 归档动作：补齐 README（三端入口、闭环验收、接口清单、已知限制）、`.env.example` 配置模板、`screenshots/` 界面快照、本 CHANGELOG。
- 运行时产物（`hotel.db`、`rag_index/`、`.env`）确认全部在 `.gitignore` 内，仓库不含密钥与本地数据。
- 无功能变更。

## v0.3.0 — 2026-10-30

- **客人房号轻量登录**：`/guest` 先录房号（1–10 位字母数字）再进服务；`sessions.room_no` 落库，员工工单池与管理端审计均展示房号；匿名会话自动重建。
- 员工端工单池 10 秒静默重拉 + 新工单标题闪烁，解决「刷新才能看到」的体验问题。
- 客人端支持 `?sid=` 定位会话，解决换浏览器后看不到回复的问题。

## v0.2.0 — 2026-10-30

- **转人工后同线程对话**：客人与员工在同一工单内双向收发，消息全量留存（`/guest/sessions/{sid}/say` 直发员工，`/staff/tickets/{sid}/reply` 回客人）。
- 转人工后的 AI 通道自动关闭，避免「AI 和员工同时回答」的混乱；会话完结后客人侧输入被拦截。

## v0.1.0 — 2026-10-30

- **三角色系统落地**：guest（免登录按会话区分）/ staff / admin。
- JWT（HS256，HttpOnly Cookie 8h）+ PBKDF2 口令 + 接口级 RBAC（`require_staff` / `require_admin`），越权返回 403。
- 员工端工单闭环：接单 → 回复 → 完结；管理端六页：知识库、提示词、页面文案、审计、账号、概览。
- 知识库多文档管理（增删 + 重建索引）；提示词与页面文案存库、每请求读取，改完即时生效。
- 对话审计：角色、房号、原文、违规标记（四类关键词确定性识别）与处理状态。
- 修复：索引文件双层嵌套 `{"docs":{"docs":{}}}` 导致重建后检索为空。

## v0.0.1 — 2026-10-30

- **员工问答入口**：FastAPI + SSE 流式问答（`status → citations → token → done`），SQLite 会话持久化（含最近 6 轮上下文）、引用条款卡片、错误重试。
- 检索复用阶段 1 混合检索（BM25 + FAISS + RRF）；未配模型密钥时降级为条款摘要流式输出。
- 接入千问 OpenAI 兼容接口（qwen-plus 生成 / text-embedding-v3 1024 维），索引按 1024 维重建，实测真实流式回答。
