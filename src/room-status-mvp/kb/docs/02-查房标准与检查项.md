# 查房标准与检查项 —— 制度

适用岗位：质检、当班领班；客房部在提交"已清扫"前应先自查一遍。

## 一、查房的定位
查房不是"再看一眼"，它是把清扫结论升级为可售结论的**唯一合法路径**。没有查房结论的房间，无论清扫做得多好，都不能报给客人。

## 二、六个必检项（全部通过才可判定通过）
1. **床品**：床单被套平整无皱、无毛发、四角包紧；枕套开口朝内。
2. **卫浴**：台面无水渍、镜面无指纹、地漏无毛发、毛巾按标准折叠、马桶封条完好。
3. **地面与家具**：地面无碎屑毛发、地毯无污渍、桌面无灰尘、行李架无残留物。
4. **客用品**：按房型标准配齐（拖鞋、牙具、茶包、矿泉水），数量与摆放位置一致。
5. **设备**：灯光全亮、空调出风正常、电视可开机、门锁与保险箱可用。
6. **气味与噪音**：无烟味、无潮味、无异味；临街房确认窗扇闭合。

任一项不合格，必须走"查房不通过"，写明返工内容并退回清扫中，不得"先放过去、入住前再说"。这是把返工成本从客人身上挪回酒店内部的唯一办法。

## 三、判定与时效
- 通过：六个检查项全部勾选通过，房态转可售，同时关闭该房的查房任务。
- 不通过：必须填写具体问题（例如"床单有毛发""淋浴地漏积水"），系统自动生成返工清扫任务并标为高优。
- 时效：已清扫后 **12 分钟内**应开始查房，查房过程 **15 分钟内**应出结论；超时在员工端标红并计入超时数。

## 四、常见误区
- "客人还没到，不着急查"：错。查房拖延直接变成高峰期的等待，等待发生在客人身上就是投诉。
- "房间今天没人订，明天再查"：错。未查房房间占用可售库存，等于虚减库存。
- "客房部自己查自己"：不允许。清扫与查房必须由不同岗位完成，谁清扫谁查房视为无效结论。
- "先给客人房卡，查房后补"：不允许。房态不是可售却开房，会被入住闸门拦截并留痕。

## 五、查房记录留什么
每次查房结论都要留：房间号、结论、检查项结果、判定人、判定时间、不合格项描述。这些记录用于交接班、投诉复盘和质检抽查，也是验收"房态错误下降"的证据链。
