# 业务挖掘 · 发现报告

> 来源：FDE 业务发现实验室（Discovery Lab）生成，项目 `travel-hotel`。完整原始报告见仓库根目录 [`discovery-report.md`](../discovery-report.md)；本文件为结构化整理版，便于快速查阅。

## 一、场景与初始诉求

山海旅居为区域连锁酒店，144 间客房、日均入住约 140 间，周末入住高峰集中在 18:00–21:00。管理层原话：

> 我们在"酒店房态与入住协同"上投入了很多人力。客房部标已清扫，前台以为可入住，但查房还没完成。管理层希望用 AI 改善，但还没有确定优先环节、验收标准、权限边界。

**问题定性**：这不是"系统不好用"，而是**三个岗位对"这间房能不能卖"的判断依据不同，且缺少统一的时间戳**。客房看"清扫结束"、前台看"可交付"、渠道看"可售"——三态没有一张共同的图。
