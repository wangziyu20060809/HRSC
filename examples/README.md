# 示例：体验协同 Demo

`src/` 即可运行的示例应用。推荐用本地服务打开（数据存 localStorage，可持久化）：

```bash
# 方式一：仓库根目录执行（等同 npm start）
npm start
# 或
bash scripts/serve.sh

# 方式二：直接进入 src
cd src && python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

也可以直接双击 `src/index.html`（file:// 打开，自动使用内嵌兜底数据 `src/data/fallback.js`）。

## 建议的演示路径（约 5 分钟）

1. **项目总览**（`#/overview`）——看 13 条事实台账与 4 项指标，注意有 5 条标「待核实」，这就是为什么报价单里验收口径写「待定」；
2. **协同 Demo**（`#/demo`）——点一间「已清扫·待查房」的房（VC）：
   - 系统自动起草交接单，标注「查房未完成」；
   - 手动把状态改成「可售」→ 确定性校验立即拦截（对应 REQ-1）；
   - 填上具名接收人并提交 → 进入人工复核队列（对应 REQ-2）；
3. **九阶段流程**（`#/pipeline`）——每阶段 3 个动作 + 1 道人工闸门，闸门必须填具名评审人才能「通过」；
4. **ROI 测算**（`#/roi`）——修改人时成本或单量，观察回收期变化；注意「复核成本按月计入」一项，它对应事实 f03；
5. **导出**（`#/export`）——下载 Markdown 成果包与 JSON 快照。
